# Potykató Pihenőpark

The new website of Potykató Pihenőpark, a family-run wedding and event venue with a lake, cabins
and fishing in the Nyíri forest near Kecskemét–Hetényegyháza. Hungarian content; all facts come
from the existing potykato.hu.

## Stack

- Next.js (App Router), TypeScript, static export (`out/`, no server needed)
- three.js only for the dot background (`kits/dot-space`)
- No other runtime dependencies

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static site in out/
```

## Where things live

| Path | What |
| --- | --- |
| `lib/site.ts` | Every fact: contact, hours, capacities, prices, amenities, reviews |
| `lib/images.ts` | Photo manifest (generated by `scripts/optimize-images.py`) |
| `lib/space.ts` | Homepage dot choreography: carp, rings, "150", cabin, black hole |
| `app/` | Pages: home, `eskuvo`, `szallas`, `horgaszat`, `arak`, `galeria`, `kapcsolat`, `adatvedelem` |
| `components/` | Header, footer, arch frames, inquiry form, slider, gallery, … |
| `public/img` | Responsive WebP photos (480/960/1440) from the original site |
| `public/art` | Engraved botanicals, carp and watercolour washes (custom illustrations) |
| `public/video` | The park's own wedding film, cropped and compressed for the hero |
| `kits/dot-space` | The dot-space engine; run `node kits/dot-space/check/stages.mjs http://localhost:3000/` to check every shape |

## Notes

- The inquiry form opens the visitor's e-mail app with a ready message to potykato@gmail.com
  (the site stores nothing). To receive submissions directly, point the form at a form service.
- The dot field uses the kit's approved motion; on this light paper theme it renders with normal
  blending, a pastel palette and slightly lower opacity (lower still on phones).
